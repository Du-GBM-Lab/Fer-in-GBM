# Gene-set inputs

Several exploratory scripts refer to locally stored ferroptosis, pathway, transcription-factor, and cell-state gene sets that are not included in this release.

For every gene-set file added later, record:

- the source publication or database and stable identifier;
- access date and database release;
- species and gene-identifier type;
- any inclusion, exclusion, or deduplication rule;
- the exact filename and checksum;
- the scripts and figure panels that use it.

Do not redistribute a third-party gene set unless its license permits redistribution.
